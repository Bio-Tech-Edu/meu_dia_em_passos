# Meu Dia em Passos

Planner visual para criança autista de cerca de 3 anos, não leitora, usado com a mediação de um adulto.
Organiza rotina, transições, emoções, alimentação e acompanhamento terapêutico, com baixa carga sensorial.

- **Instruções para IAs:** [`github_instructions.md`](github_instructions.md)
- **Prompts por tipo de IA:** [`prompts/`](prompts/)
- **Versão digital:** [`src/`](src/) (HTML/CSS/JS puros, funciona sem internet)

> Nenhum dado real da criança deve entrar neste repositório nem em ferramentas de IA. Use "Criança A" ou "[NOME]".
